# TaskFlow – Web-Based Task Management System

A feature-rich, responsive task management web application built with HTML, CSS, and JavaScript.

## 📋 Project Overview

**Title:** Web-Based Task Management System  
**Type:** RFP (Request for Proposal) College Project  
**Technologies:** HTML5, CSS3, Vanilla JavaScript  
**Storage:** Browser LocalStorage (no backend required)

## ✨ Features

- **Dashboard** – Overview of all tasks with stats, priority breakdown, quick-add
- **Task Management** – Full CRUD (Create, Read, Update, Delete) for tasks
- **Filtering & Sorting** – Filter by status, priority, category; sort by date/priority
- **List & Grid Views** – Toggle between list and grid views for tasks
- **Projects** – Organize work into projects with progress tracking
- **Calendar View** – Visualize tasks on an interactive monthly calendar
- **Analytics** – Charts showing task distribution by status, priority, category
- **Settings** – Profile management, notification preferences, data export
- **Responsive Design** – Works on desktop and mobile
- **Dark Theme** – Modern dark UI with accent colors

## 🚀 How to Run

1. **Clone or download** this repository
2. **Open `index.html`** in any modern browser
3. No server, no installation needed – it runs purely in the browser!

```bash
git clone https://github.com/YOUR_USERNAME/taskflow.git
cd taskflow
# Open index.html in browser
```
